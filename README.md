# vishwavedhika-ayurvedic-clinic

Official website for **Shri Vishwawedhika Ayurvedic Center & Panchakarma Garbha Sanskar Center**, located in Kharadi, Pune, Maharashtra.

## Overview
Shri Vishwawedhika Ayurvedic Center is dedicated to authentic, classical Ayurvedic healthcare, traditional Panchakarma detoxification, chronic spine and back care, stroke rehabilitation, and Garbha Sanskar prenatal/postnatal guidance supervised by Dr. Manjiri.

## Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) 16 (App Router & Turbopack)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) v4
- **Icons:** [Lucide React](https://lucide.dev/)
- **SEO & Structured Data:** JSON-LD LocalBusiness, MedicalBusiness, and FAQPage schemas, dynamic `sitemap.xml`, `robots.txt`, and `llms.txt`
- **Deployment Target:** Cloudflare Pages / Vercel

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production

```bash
npm run build
npm run start
```

## Cloudflare Pages Deployment
This project is configured for seamless deployment on **Cloudflare Pages**:
- **Build command:** `npm run build`
- **Build output directory:** `.next` (or static export `out`)
- **Node.js version:** `>= 20.x`
- Images are pre-configured with `unoptimized: true` for zero-configuration Cloudflare Pages compatibility.
